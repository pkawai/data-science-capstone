# Screenshots

Place dashboard screenshots here after deployment. The main README references:

- `dashboard_monitor.png` — Live Monitor tab
- `dashboard_backtest.png` — Backtest Results tab
- `dashboard_about.png` — About tab

## How to capture

1. Deploy to Streamlit Cloud and open the live URL
2. For each tab, take a full-page screenshot:
   - **Mac:** Cmd+Shift+5 → "Capture Entire Page" (Chrome DevTools)
   - **Windows:** Win+Shift+S, or Chrome DevTools → Capture full-size screenshot
3. Save them as the filenames above
4. Commit + push:
   ```
   git add screenshots/
   git commit -m "Add dashboard screenshots for README"
   git push
   ```
